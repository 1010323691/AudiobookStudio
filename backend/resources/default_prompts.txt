### SPEAKER AND TEXT

- `speaker` = the exact Chinese character name from the source for spoken dialogue.
- `speaker` = `NARRATOR` for everything not explicitly spoken aloud.
- `NARRATOR` is the only special speaker ID. Never use `旁白` or other narrator names.
- Never generate, translate, romanize, abbreviate, or replace character names.
- Preserve the source text exactly. Never translate, paraphrase, summarize, rewrite, or omit it.
- `text` must remain Chinese. English is allowed only in `instruct` and the fixed `NARRATOR` ID.

### RULES

1. NARRATOR VS CHARACTER
   - CHARACTER = words explicitly spoken aloud.
   - NARRATOR = descriptions, actions, thoughts, internal monologue, scene-setting, exposition, and narrative commentary.
   - Never turn narration or thoughts into dialogue.
   - Never put narration inside a CHARACTER entry.

2. DIALOGUE BOUNDARIES
   - Every spoken dialogue segment MUST be a separate CHARACTER entry.
   - Never put dialogue inside a NARRATOR entry.
   - Narration grouping MUST NEVER cross a dialogue boundary.
   - For mixed paragraphs, split strictly at each dialogue boundary:
     narration → dialogue → narration → dialogue.
   - Dialogue boundary has higher priority than narration grouping.
   - Remove only the outer dialogue quotation marks.

3. ATTRIBUTION AND ACTIONS
   - Remove pure speech-attribution tags such as “他说”“她回答”.
   - Preserve descriptive actions as NARRATOR.
   - If an extracted action uses a pronoun, replace it with the character's original name only when needed for standalone clarity.
   - Do not otherwise rewrite the extracted narration.

   Example:
   “没什么可说的。”马库斯说着，无法直视她的目光。
   →
   {"speaker":"马库斯","text":"没什么可说的。",...}
   {"speaker":"NARRATOR","text":"马库斯无法直视她的目光。",...}

4. NARRATION GROUPING
   - Keep consecutive narration in ONE entry.
   - Do not split narration sentence-by-sentence.
   - Split narration only when a dialogue boundary or a clear scene/tone/narration-mode change requires it.

5. SPECIAL CASES
   - Characters reading documents aloud speak the document's text and are assigned the reader's name.
   - Non-human characters that do not explicitly speak are NARRATOR.
   - Preserve internal quotation marks; remove only outer dialogue quotes.
   - Do not use bracketed sounds such as `[gasps]` or `<sigh>`.

6. INSTRUCT
   - Describe audible emotional tone, intensity, delivery, and vocal quality.
   - Do not describe physical actions as vocal direction.
   - NARRATOR default: `Neutral, even narration.` Change it only when the narrative tone clearly changes.
   - CHARACTER instructions must match the dialogue's emotional state and context.
   - Preserve emotional continuity with nearby lines.
   - Use concise, natural vocal directions, normally 1–2 sentences and ~8–25 English words.
   - Avoid weak qualifiers such as “slightly” or “a bit”.

### FINAL CHECK

Before outputting JSON, verify:
- Every spoken dialogue segment has its own CHARACTER entry.
- No NARRATOR entry contains spoken dialogue.
- No CHARACTER entry contains narration or actions.
- No source narration or dialogue was omitted or rewritten.
- Character names are unchanged.
